# 论文模板目录说明

本目录包含各类学术论文和文档模板,按用途分类如下:

## 📁 目录结构

### 1. 国际期刊模板 (IEEE系列)
- **`IEEE/`** - IEEE官方通用模板
- **`IEEE-Transactions-LaTeX2e-templates-and-instructions/`** - IEEE Transactions LaTeX模板及说明
- **`IEEE-Transactions-LaTeX2e-templates-and-instructions.zip`** - IEEE模板压缩包

### 2. 中文期刊模板
- **`电工技术学报/`** - 《电工技术学报》论文模板
- **`《电工技术学报》论文模板.docx`** - 《电工技术学报》Word模板文件
- **`电网技术/`** - 《电网技术》期刊模板

### 3. 其他学术模板
- **`AAS_Template_LaTeX/`** - AAS (可能为某学术协会) LaTeX模板

### 4. 通用文档模板
- **`coverletter.docx`** - 投稿封面信(Cover Letter)模板

### 5. 研究资料
- **`电力预测/`** - 电力预测相关资料

## 📝 使用建议

### LaTeX模板使用
1. 确保已安装LaTeX发行版(如TeX Live、MacTeX或MiKTeX)
2. 使用LaTeX编辑器(如Overleaf、TeXShop、VS Code + LaTeX Workshop)打开
3. 阅读模板中的说明文档,了解具体格式要求

### Word模板使用
1. 使用Microsoft Word或兼容软件打开
2. 注意保留模板的样式设置
3. 填写内容时遵循模板的格式规范

### 投稿前检查
- [ ] 检查期刊的最新投稿要求
- [ ] 确认模板版本是否为最新
- [ ] 验证参考文献格式是否符合要求
- [ ] 检查图表是否清晰并符合规范
- [ ] 准备好Cover Letter和其他必要文件

## 🔧 模板维护建议

1. **定期更新**: 期刊模板可能会更新,建议定期从官网下载最新版本
2. **版本管理**: 建议为不同期刊的模板添加版本号或更新日期
3. **备份原始模板**: 修改前先备份原始模板文件
4. **记录修改**: 在模板文件夹中添加README文件记录修改内容
